# キープオンラボ PWA — 構築仕様（Claude Code 用）

## ゴール（これを完成させて）
キープオンラボに通っているスクール生・保護者のための**PWAアプリ「キープオンラボ」**を、ローカルで動く状態まで作り切ってほしい。Instagramのような操作感で「見て・知って・動ける」アプリ。役員会で承認済みのデザイン提案（同梱モックアップ）を実装に落とす仕事です。

## なぜ
- 対象は**保護者と通学中の生徒**。専門知識のない人がスマホで直感的に使えることが最優先。
- 世界観はCLAFTの「クラフト紙・手書き・スクラップブック」を継承。**温かみと信頼**を両立させたい。
- アプリ化の最大の価値は**新着イベントのプッシュ通知**。ここを軽視しない。
- ロゴの思想は「0→1コミュニティ」。受け取るだけでなく、**言う・つくる側に回れる導線（アイデア箱）**を設計に残すこと。

## 完成の定義（証拠ベースで確認して報告）
次がすべて満たされた状態を「完成」とする。各項目は**実際にdevサーバーを起動し、ブラウザ/スクショで確認してから**報告すること。「できたはず」で報告しない。
- [ ] `npm run dev` が無警告で起動し、トップ画面が表示される
- [ ] トップ＝ヘッダー＋ストーリーズ（横スクロール）＋フィード（縦スクロール）＋下段固定バーの4ブロックが揃う
- [ ] 6つのストーリーカテゴリと、6画面（トップ/ストーリー閲覧/受講予約/面談申込/アイデア箱/ラボの歩き方/設定）が遷移できる
- [ ] 受講予約・イベント予約の外部リンクが正しく開く
- [ ] PWAとしてインストール可能（manifest + Service Worker が有効、Lighthouse PWA項目がパス）
- [ ] スマホ幅（375px）で崩れない。キーボードフォーカスが見える。`prefers-reduced-motion` を尊重

## 境界線（ここから〜ここまで）
**やること**：上記スコープのフロントエンド実装、ダミーデータでの動作、PWA化。
**やらないこと（勝手に進めない）**：
- 本番デプロイ・Vercel公開はしない（ローカル完成まで）
- フォームの送信先確定（面談・アイデア箱）は**未定**。送信ボタンは置くが、送信先は `TODO` コメントで止めて私に確認すること
- Web Push の VAPIDキー発行や外部サービス契約はしない。通知UIと購読フックの**ガラ**まで作って、鍵が要る箇所はTODOで止める
- 既存 `claft-HP` の公開ページを壊す変更はしない
- npm以外からの不審なパッケージ取得、認証情報の入力はしない

## 技術前提（既存CLAFT HPに揃える）
- Next.js 14 (App Router) / TypeScript / Tailwind CSS + styled-jsx
- フォント：Zen Maru Gothic（見出し）/ Noto Sans JP（本文）
- PWA：`next-pwa` もしくは Serwist（動く方を選んでよい。選定理由を一行残す）
- 配置：**`claft-HP` リポジトリ内に `app/(lab)/` ルートグループを新設**する前提で進める（HPコンテンツ連携を見据えて）。難しければ独立構成にし、理由を報告

## 画面仕様
### 共通：ヘッダー
- 左：ロゴ「」
- 右：手紙アイコン（＝**アイデア箱**、InstagramのDM位置）。未読バッジ可

### ① トップ `app/(lab)/page.tsx`
- **ストーリーズ**：円形ボタンを横スクロール。`募集イベント / 発表会 / キャリアインタビュー / スクール生紹介 / Yononaka / 今週のスクールフォト`。リングは紺→緑→オレンジのグラデ
- **フィード**：お知らせ・活動報告カードを縦スクロール（1画面に約3枚）。サムネ＋カテゴリチップ＋タイトル＋日付＋「くわしく見る →」
- **下段固定バー**：`受講予約`（オレンジ＝最重要・一番大きく）/ `面談申込`（紺アウトライン）/ `ラボの歩き方`（緑）

### ② ストーリー閲覧 `app/(lab)/story/[category]/`
- カテゴリの円タップ→**全画面でスワイプ閲覧**（Instagram挙動）。上部に進行ドット
- 最後のカードに「**詳細ページを見る →**」ボタン → CLAFT HPの該当ページへ

### ③ 受講予約 `app/(lab)/reserve/`
- 画像ボタン2つ：
  - **受講予約** → `https://select-type.com/rsv/?id=3spOTwJvnpQ&c_id=429087`（外部・別タブ）
  - **イベント予約** → `https://claft-hp.vercel.app/news`

### ④ 面談申込 `app/(lab)/meeting/`
- 個別面談フォーム（氏名・連絡先・希望日時など）。送信先は `TODO`

### ⑤ アイデア箱 `app/(lab)/idea/`
- 右上手紙アイコンから遷移。投稿フォーム。送信後に「ラボに届きました」的な温かい完了画面（双方向感）。送信先は `TODO`

### ⑥ ラボの歩き方 `app/(lab)/guide/`
- 初めての人向け使い方ガイド（各機能の説明）

### ⑦ 設定 `app/(lab)/settings/`
- **プッシュ通知のON/OFFトグル**（複数粒度可：全体・新着イベント）
- 「ホーム画面に追加」案内

## デザイントークン
```
--navy:   #213a5a   /* 基調：ヘッダー・文字・土台 */
--orange: #ef8a3c   /* アクセント：受講予約など最重要CTAだけに使い希少化 */
--green:  #74ab3d   /* サブ：アクティブ状態・補助線 */
--paper:  #f3ead9   /* クラフト紙の下地 */
--card:   #fbf6ec   /* カード面 */
--ink:    #2b2b2b   /* 本文 */
--line:   #cdbf9f   /* 罫・枠 */
```
- 質感：クラフト紙テクスチャ（微細グレイン）、角丸、手書き風のやわらかさ、カードに紙のドロップシャドウ
- **色の序列を守る**：オレンジは「今してほしい行動」だけ。乱用しない

## データの流れ（段階的に）

3. （将来）CMS等へ

## 進め方（手順は任せる。原則だけ）
推奨の組み立て順：①骨格（レイアウト＋ヘッダー＋固定バー）→②ストーリーズ＋フィード（ダミー）→③各機能ページとリンク→④ストーリービューア→⑤PWA化→⑥通知UI。ただし順序は最適と思う形でよい。

- **進捗は証拠ベースで**：節目ごとに、何を作り・どう確認したか（起動ログ/スクショ/該当パス）を添えて報告
- **判断に迷ったら、止めて私に一問だけ聞く**（特に送信先・リポ構成）
- **教訓メモを持つ**：リポ直下に `LESSONS.md` を作り、詰まった点・解決・以後の方針を書き溜めながら進めること
- 宣言だけして手が止まったら、私が「続けて」と送る。そのまま再開してよい

最初の一手として、リポ構成（相乗り or 独立）の方針だけ決めて、`app/(lab)/page.tsx` の骨格から着手してください。
