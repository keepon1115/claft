# ラボ ストーリーズ用の動画置き場

`stories.data.ts` の `cards[].videoUrl` から参照する動画ファイルをここに置く。

## 動画を追加する手順

1. 動画ファイルをこのフォルダ（`public/videos/lab-stories/`）に置く。
   - 形式：**mp4（H.264）**
   - 長さ：**5秒程度**（ストーリーの自動送りが約6秒のため、それより短めがちょうどいい）
   - 向き：縦長 9:16 推奨（全画面表示のため）
   - 容量：軽いほど良い（スマホ回線での初期読み込みを考慮。目安 3MB以下）
   - ファイル名：英数字・ハイフンのみ（例 `event-0826.mp4`）
2. `lib/lab/stories.data.ts` の該当カードに `videoUrl: '/videos/lab-stories/ファイル名.mp4'` を追加する。
   - 音声は自動再生の都合で常にミュート表示になる（`StoryViewer.tsx` 側で `muted` 固定）。
   - `imageUrl` を残しておくと、動画の読み込み中の一瞬（poster）に使われる。
3. 差し替え・削除するときは、このフォルダの古いファイルも一緒に消す（消し忘れるとリポジトリだけ肥大化する）。
4. `git add` してコミット・デプロイすれば反映される（画像と違って外部CDNは使わず、リポジトリに同梱する運用）。
