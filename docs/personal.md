コンテンツ量産パターン
Pattern 1｜引っかかり × AIオープンクエスチョン
毎日感じた「引っかかり」をつぶやく

→ AIがオープンクエスチョンで問い返す

→ 話す・答える

→ 記事になる
強み： 日々の学びをそのまま形にできる。量産と継続が両立しやすい。

Pattern 2｜子育て・学び × 学際的知見
問い：既存の学校教育では、今後の社会に立ち行かなくなるのではないか。
自分の息子を一つの実験台に、「人はどう成長するか」「学ぶとは何か」「学び続けるにはどうするか」「何に喜びを見出すか」を探求していく。
参照する知見：仏教・心理学・脳科学・神経科学・AI
プロセス：気になったこと・引っかかったことをそのまま質問し、答えていくことで記事を生成する。

Pattern 3｜クリエイター路線（実験枠）
脈絡のないアイデアをそのまま放り込む。

それが歌になるかもしれない。ゲームになるかもしれない。

論理より感覚、整合性より発見。
