# ガイドモード 担当者ガイド(初稿・2026/11/17)

CLAFT通学の「ガイドモード」を担当するスタッフ向け。だれが担当しても同じ進め方ができるようにするための手引き。
「ガイドモード」「ガイドコース」は内部の呼び名で、保護者や子どもには使わない。

試す2人の学年・好きなこと・困りごとはまだ入れていない。決まったら「6. その子のメモ」に書き足す。

## 1. 概要

| | |
|---|---|
| 目的 | テーマが定まらない子が、自分の探究テーマにたどり着き、自分で進められるようになる |
| 対象 | テーマが定まらない／作品を出したがらない／振り返りを書かない／やる気にムラがある子 |
| 時間 | 月2回、1回60分 |
| 期間の目安 | 4回(約2か月)でテーマを1文にする。合わなければ延ばしてよい |
| スタッフの役割 | 教えるより、引き出す。決めるのは子ども |

### 大事にすること

- **書くことを強制しない。** 話すだけでいい。書くのはスタッフでもいい。
- **パスしていい。** 「今日は答えたくない」「今日はやりたくない」を最初に認める。
- **評価しない。** 「上手」「えらい」より、「ここ、もっと聞きたい」「ここに気づいたんやね」と返す。
- **テーマは変わっていい。** 途中で変えるのは失敗ではなく、進んだ証拠。

## 2. 1回60分の型(毎回おなじ)

| 時間 | すること | スタッフの発話の例 |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「今日の調子は、晴れ・くもり・雨のどれ？」(理由は聞かなくていい) |
| 0:05〜0:15 | 聞く | 「この2週間で、いちばん時間を使ったことって何？」 |
| 0:15〜0:45 | 手を動かす | その回のワーク(下の3章)。スタッフは横で一緒にやる |
| 0:45〜0:55 | 振り返り | 3つの形から、その子に合うものを選ぶ(4章) |
| 0:55〜1:00 | おうちへの一言 | 「今日のこと、おうちの人に一言で伝えるなら？」→ スタッフが写真と一緒に送る |

「雨」の日は、ワークを半分にして、残りは好きなことをしてよい。来ただけで十分と伝える。

## 3. テーマ発見までの4回

### 第1回「好きを並べる」(シート①:好きマップ)

- ねらい:好きなもの・気になるものを、良い悪いをつけずに全部出す。
- 進め方:紙の真ん中に名前を書き、まわりに「好き」「よくやる」「最近気になる」を書き出す。スタッフが聞いて書く。10個を目安に。
- 聞き方:「休みの日、気づいたら何してる？」「動画は何を見てる？」「それの、どこが好き？」
- 終わりに:いちばん話していて楽しそうだった1〜2個に、本人が丸をつける。

### 第2回「なんで？を見つける」(シート②:はてなメモ)

- ねらい:好きなものから、調べたい・試したい「はてな」を見つける。
- 進め方:丸をつけた1個について、「なんで？」「どうやって？」「もし〜だったら？」を3つ出す。
- 聞き方:「それ、どうやって作られてると思う？」「もし自分が作るなら、どこを変える？」
- 出ないとき:スタッフが自分の「はてな」を1つ言ってみせる。答えは言わない。

### 第3回「ちょっと試す」(シート③:おためしカード)

- ねらい:15〜20分でできる小さなことを、1つやってみる。
- 進め方:はてなを1つ選び、「今日ここでできること」に小さくする。調べる、描く、作る、まねしてみる、のどれでもいい。
- カードに残すこと:やったこと／わかったこと／次にやってみたいこと(スタッフが聞き書きでよい)。
- 大事な点:完成しなくていい。「途中」の写真を1枚撮る。

### 第4回「テーマにする・見せ方を選ぶ」(シート④:テーマカード)

- ねらい:テーマを1文にして、だれにどう見せるかを自分で選ぶ。
- テーマの型:「〇〇を、△△してみる」(例:「好きなゲームのしかけを、自分のゲームでまねしてみる」)。
- 見せ方は3つから選ぶ:
  1. 展示会や発表会に出す
  2. 1人だけに見せる(スタッフ、友達、おうちの人)
  3. スタッフが代わりに紹介する(本人は横にいるだけでいい)
- どれを選んでも「見せた」ことになる。3から始めて、次に2へ進めばいい。

### 自分で進める形(自走)に移る目安

次の3つがそろったら、スタッフは声かけとヘルプ中心に切りかえる。

- 教室に来て、自分から「今日これやる」と言える日が2回続いた
- テーマの1文を、自分の言葉で言える
- 見せ方を1つ、自分で選んだ

そろわなくても急がない。5回目以降は、第2回〜第4回をもう一度まわす。

## 4. 振り返りの3つの形(どれか1つでいい)

| 形 | やり方 | 向いている子 |
|---|---|---|
| A 聞き書き | スタッフが3つ質問して、シートに書く。「今日やったこと」「おもしろかったところ」「次にやりたいこと」 | 話すのは平気だが、書くのがいやな子 |
| B 話す動画 | 作品や手元を映しながら、1分だけ話してもらう。あとでAIで文字にする。顔は映さなくていい | 作品を見せながらだと話せる子 |
| C スタッフの一言と写真 | 子どもには何も求めない。スタッフがその日の様子を2〜3行と写真1枚で残す | 話すのも気が進まない日。やる気が低い日 |

### どれにするかの早見表

1. まず本人に聞く。「今日は、話す・撮る・おまかせ、どれにする？」
2. 答えがない、または調子が「雨」なら → C
3. 作品や画面を見せたがっているなら → B
4. それ以外 → A

毎回ちがってよい。3回続けてCなら、次は「一言だけ」のAをさそってみる。

### 保護者に届けるもの

どの形でも、毎回「写真1枚＋2〜3行」をLINEで届ける。内容は、やったこと・本人の言葉(あれば)・次にやること。評価の言葉(がんばった、集中していた)より、事実を書く。

## 5. こんなとき(判断の分かれ道)

| こんなとき | こうする |
|---|---|
| 何を聞いても「べつに」「わからん」 | 10秒待つ。それでも出なければ、2つから選べる聞き方にする(「作るのと調べるの、今日はどっち？」) |
| 好きなものが出てこない | 「きらいなもの」「めんどうなこと」から聞く。そこにもこだわりがある |
| 毎回テーマが変わる | 止めない。変わった理由を1つだけ聞いて、シートに残す。3回分ならべると、共通点が見えることが多い |
| 作品を見せるのをいやがる | 理由を聞きすぎない。見せ方3(スタッフが紹介)を提案する。それもいやなら、今回は出さない |
| ゲームや動画だけで60分終わりそう | 禁止しない。最後の10分だけ「どこがおもしろかった？」を聞いて、はてなメモに足す |
| 今日は何もしたくない | 「来てくれてよかった」と伝え、振り返りはCにする。次回の最初に、前回の写真を一緒に見る |
| スタッフに答えを聞いてくる | 「どう思う？」で一度返す。それでも困っていたら、調べ方を一緒に探す |

## 6. やらないこと(理由つき)

| やらないこと | 理由 |
|---|---|
| スタッフがテーマを決めてあげる | 自分で決めた感覚がないと、続かない |
| 沈黙を埋めるために、先に答えを言う | 考えている時間を取ってしまう |
| 書かせる、清書させる | 書くことがいやで、探究そのものがいやになる |
| ほかの子とくらべる(「〇〇くんはもう出したよ」) | 見せることが、こわいものになる |
| 「それ、何の役に立つの？」と聞く | 好きの入口をふさぐ。意味は後からついてくる |
| 保護者への報告で、できなかったことを並べる | 保護者の不安だけが増える。事実と次の一歩を伝える |

## 7. 手順にできること・できないこと

- **手順にできる**:60分の時間配分、4回の流れ、振り返りの選び方、保護者への届け方、やらないこと。
- **担当者にまかせる**:その子の表情を見て質問を変えること、ワークを途中で切り上げること、テーマの言い回しを一緒に探すこと。ここは決まった答えがないので、担当者の判断でよい。迷ったら、その日のうちにほかのスタッフに一言共有する。

## 8. その子のメモ(担当を交代するときの引き継ぎ)

1人1枚。担当が変わっても、これを読めば続きができるようにする。

| 項目 | 記入 |
|---|---|
| 呼び名・学年 | |
| 好きなこと(シート①から) | |
| いまのはてな(シート②から) | |
| いまのテーマ(1文) | |
| 合っている振り返りの形(A/B/C) | |
| 調子が出るきっかけ | |
| さけたほうがいいこと | |
| 前回やったこと／次にやること | |
| 保護者に最後に届けた日と内容 | |

## 用意するもの

- シート①〜④(A4・1枚ずつ。これから作る)
- その子のメモ(上の表)
- スマホ(写真・動画用)、ペン、付箋

## これから決めること

- 試す2人の情報を「その子のメモ」に入れる
- シート①〜④のデザイン
- 保護者に、進め方が変わることをどう伝えるか(「ガイドモード」という言葉は使わない)
- 1月の2人で試したあと、どこを直すかを見る日
