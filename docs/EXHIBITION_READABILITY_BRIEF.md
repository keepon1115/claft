# なんでも展示会 紹介ページ「視認性改良」指示書

作成日: 2026-07-07 ／ 発注者: オーナー（キープオン） ／ 状態: **実装待ち**
必読の姉妹文書: **docs/RESPONSIVE_DESIGN_KNOWLEDGE.md**（本件の原因類型と直し方の一般則。先に読むこと）

## 0. 背景

`/futurecraft/Exhibition`（紹介ページ）で、ヒーローの浮遊ポラロイド写真がタイトル・キャッチコピーに
被って文字が読めない（スマホ実機スクショで確認済み）。加えて PC では本文の行長が長すぎて読みにくく、
「PCの中央カラムとスマホがほぼ同じ幅なのに見た目が別物」という不整合が全体にある。

**ゴール: どの画面幅でも文字に飾りが被らず、同じ幅のカラムなら同じ見た目になること。**

## 1. 対象ファイル

| 区分 | ファイル |
|---|---|
| 主対象 | `app/(site)/futurecraft/Exhibition/NandemoTenjikaiContent.tsx`（紹介LP本体） |
| 軽微調整 | `app/(site)/futurecraft/Exhibition/[slug]/page.tsx`（ギャラリー。§5のみ） |

## 2. ヒーロー再構築（最重要）

現状: ポラロイド4枚が `absolute inset-0` ＋ %座標（`left-[2%] top-[12%]` 等）で
セクション全面に浮いており、中央テキストと同じ空間を取り合って必ず被る。

### 2.1 スマホ（base、〜639px）: 絶対配置を全廃して通常フローに

上から順に縦積み:

1. リボン（✦ Open Gallery 2026 ✦。現状維持だが absolute をやめてフロー化してよい）
2. 「ようこそ、世界でいちばん自由な展示会へ」
3. タイトル「なんでも展示会」（Sparkles 付き）
4. キャッチコピー（あなたの「好き」を〜）
5. **ポラロイド2枚を横並びストリップ**（`flex justify-center gap-4`、各 `w-[40%]` 上限、
   回転 ±5deg 程度、`float-anim` 維持。使用する2枚は「うちのウサギ、もちこ」「マイクラの大ぼうけん」）
6. scroll down インジケーター

残り2枚（ひとりバンド演奏／はじめてのMV）はスマホでは表示しない（現状も `hidden sm:block`）。

### 2.2 PC（sm以上）: セーフゾーン式3カラムグリッド

```
grid-cols-[1fr_minmax(0,42rem)_1fr]  （目安。左右レール／中央テキスト）
```

- 左レールに2枚・右レールに2枚のポラロイドを縦に配置（レール**内**で `float-anim`・回転は維持）
- 中央カラムはテキスト専用。**写真は構造上ここに入れない**（%座標での重ね置きを復活させない）
- レールが狭い中間幅（640〜900px）では写真幅を `clamp` や `max-w` で縮めてはみ出しを防ぐ
- `pt-32 sm:pt-44` のような「写真を避けるための余白ハック」は不要になるので撤去
- `min-h-[100svh]` は維持してよいが、%座標の縦位置指定（`top-[12%]` 等）は全廃

## 3. 読みやすさの底上げ（紹介ページ全セクション共通）

1. **行長制限**: 連続した文章（`<p>` の本文）はすべて `max-w-prose mx-auto`（左寄せセクションは mx なし）。
   カードグリッド（たとえば6例・いいところ4枚・付箋・OK/NG）はカード自体の幅制限で足りるので対象外。
2. **コントラスト**: 情報を持つテキストの不透明度は **最低 `/70`**（現状の `/50` `/60` を引き上げ）。
   純粋な飾りラベル（`— ABOUT` 等）は現状維持でよい。
3. **見出しのジャンプ幅**: ブレークポイント間の文字サイズ差は**1段階まで**。
   - h1「なんでも/展示会」: `text-6xl sm:text-8xl` → `text-5xl sm:text-7xl`
   - 各セクション h2: `text-4xl sm:text-6xl` → `text-3xl sm:text-5xl`
   - CTA h2: `text-4xl sm:text-7xl` → `text-4xl sm:text-6xl`
   （視覚的な迫力は落とさない範囲で。数値は目安、1段階差ルールの方が優先）
4. **テキストの回転を弱める**: 文章が乗る要素（引用ふきだし `rotate-[-2deg]`、付箋 ±1.5deg）は
   **±1deg 以内**に。写真・マスキングテープ・スタンプの回転は演出なので現状維持。

## 4. リンク切れ修正

- 「なんでも発表会」もあるよ ボタン: `href="#"` → **`/futurecraft/Presentation`**
- LINEボタン・メールボタン: **リンク先未定のため現状維持（`href="#"` のまま触らない）**。
  オーナーからURL支給後に別途差し替える。

## 5. ギャラリーページの整合（軽微）

`[slug]/page.tsx` は本文カラムが `max-w-3xl` で概ね良好。以下のみ:

- h1: `text-4xl sm:text-6xl` → `text-4xl sm:text-5xl`（1段階差ルール）
- 情報テキストの `/45` `/50` → `/60` 以上（日付バッジ・注記類）
- それ以外（目次・作品セクション・リアクション・コメント欄）は**触らない**

## 6. デザイン上の制約（厳守）

- 文言・フォント（Kaisei Decol / Zen Kaku Gothic New / Yusei Magic）・ブランド配色
  （#FFF8EC / #1F1810 / #E04E2C / #F2B544 / #2E7D7D / #E89BB0）は変更不可
- 紙もの・テープ・付箋・グレイン・`.reveal` フェードインの世界観は維持。
  「読みやすくする」ことと「にぎやかさを消す」ことは別。飾りは**テキストの外**で今まで通り遊ばせる
- `prefers-reduced-motion` 対応を維持

## 7. 検証手順（実装後に必ず実施）

1. `npm run dev`（ポート3002）で以下4幅を確認: **320px / 375px / 768px / 1280px**
   ＋ **PCでウィンドウを640px前後まで狭めた状態**（ここが従来一番崩れる）
2. どの幅でも: ヒーローの文字にポラロイドが1pxも被らない／横スクロールが発生しない
3. 375px と「PC窓を375px相当に狭めた表示」で、本文カラムの見た目が実質同じであること
4. 「なんでも発表会」ボタンが `/futurecraft/Presentation` に遷移する
5. `/futurecraft/Exhibition/nandemo-2026-07`（ギャラリー）も4幅で崩れがないこと
6. `npm run build` が通ること
7. 完了後、**docs/RESPONSIVE_DESIGN_KNOWLEDGE.md の検証チェックリストを全項目実施**
