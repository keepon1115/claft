## 当日の写真(#10)の差し込み方

1. 前日までに、#10 を仮の写真12枚で埋めた「完成版A」を書き出しておく(差し込みが間に合わないときの保険)。
2. 当日、写真係のスタッフ1人が、3つのイベントと展示コーナーを撮る。
3. 15:00 に写真をしめ切り、12枚を選ぶ。選ぶ目安:3つのイベントから各3枚、展示コーナーから3枚。同じ子ばかりにならないようにする。
4. Canvaで12枚を差しかえ、「完成版B」を書き出す(15:30まで)。
5. 15:45 までに会場の機材で頭出しを確認する。間に合わなければ完成版Aを流す。
