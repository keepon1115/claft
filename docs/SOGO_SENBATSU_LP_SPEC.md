## §1 概要

| 項目 | 内容 |

## §2 デザイン原則（夕方の声の実装ルール）

このページは既存のYononaka系ページ（`app/(site)/yononaka/page.tsx`）と同じ流儀で作る。

1. **ベース面**: 既存トークンを使う。`--paper`(#fffdf6)＝主背景、`--paper-warm`(#fdf6e7)＝面の重なり。元設計書の`--surface-base`/`--surface-raised`はこの2つに対応する。**新しい色トークンを:rootに足さない。**
2. **アクセント（灯り）**: セクションのルート要素に `style={{ ['--accent-rgb' as string]: '224 158 22' }}` をインライン注入する（yononaka/english-steamページの既存慣例）。元設計書の#f5a623はこの深いアンバー(#e09e16)で代替する——クリーム`--cream`(#ffd66b)は白文字とコントラスト不足のため、バッジ・面には必ず`224 158 22`側を使う。
3. **アクセントは面・線・マーカーにだけ使う。本文の文字色には使わない。** 文字は`--ink-900`系。
4. **アンカー証**: `#34c6be`は`var(--brand)`または`rgb(var(--brand-rgb))`のトークン参照のみ（生hex直書き・再定義禁止）。ページ内に小さく1点だけ入れる（§4 S8参照）。
5. **フォント**: 追加設定不要（layout.tsxでZen Maru Gothic＋Noto Sans JPが読込済み）。本文既定はZen Maru。**S5以降の保護者ゾーンの長文段落のみ `font-family: var(--font-noto)`** に切り替える（声の切り替えを筆跡でも表現）。
6. **文字サイズ**: vwのclampを書かない。既存の`--text-xs`〜`--text-6xl`トークンのみ使用。
7. **手描き要素は控えめに**: `components/craft/HandDrawn.tsx`のUnderline程度は可。DoodleIconの多用・キャラクター的装飾は禁止（中高生以上向けで子ども扱いに見える）。傾き`--rot`は±1deg以内の微小に留める。
8. **グラデーション禁止**（例外: S1の「灯り」1点のみ、radial-gradientで`--cream`を透過8〜12%程度に淡くにじませるのは可。それ以外は単色面＋差し色）。
9. レイアウト崩れの対処は `docs/RESPONSIVE_DESIGN_KNOWLEDGE.md` を先に参照すること。

### S2｜この場所の3つのルール（sg-rules）

カリキュラムより先に安全性を宣言するセクション。**3行だけを、大きく、余白たっぷりに。** 装飾を足さない（このセクションの主役は順序そのもの）。

- 小見出し（eyebrow）: 「はじめに、この場所のルール」
- 本文（`--text-2xl`前後、白紙片`craft-paper--white`1枚に3行、番号は丸数字でなくアンバーの小さな番号スタンプ）:

  > ① 話したくないときは、パスしていい。
  > ② カメラはオフでもいい。
  > ③ 失敗は、次のアイデアへのギフト。

### S3｜8回の旅の地図（sg-journey）

- 構成: 縦タイムライン。左に灯りの丸マーカー（01〜08の番号入り、`--accent-rgb`面）、縦の点線でつなぐ。各回は`<details>/<summary>`のアコーディオン（既存`.cd-acc`のdetails式実装を**参考に**`sg-acc`として新設。cd-*クラスを直接流用しない）。
- **このセクションでは「対策」「合格」「入試」の語を使わない**（体験の言葉だけ）。
- 8回のタイトルと説明（開いたときの1〜2文）:

  | # | タイトル | 説明文（確定稿） |
  |---|---|---|
  | 01 | 引っかかりの考古学 | 「なんか気になる」を発掘する回。好きなもの、違和感、引っかかり——机に全部並べて、きみだけの地層を掘ってみる。 |
  | 02 | 手で作る自分 | 言葉にする前に、手を動かす。工作やコラージュで「いまの自分」をかたちにしてみると、話せることが増えている。 |
  | 03 | 強みの棚卸し | できないことではなく、できてしまうことを数える回。自分では当たり前すぎて見えない強みを、対話の中で見つける。 |
  | 04 | 4つの問い | 「何をしてきた？」「何が好き？」「何を学びたい？」「その先で何をしたい？」——きみの物語の骨になる4つの問いと、はじめて向き合う。 |
  | 05 | Talk Tacticsで遊ぶ | カードゲームで「話す・聞く」を遊ぶ回。うまく話すためじゃなく、話すことが少し楽しくなるために。 |
  | 06 | 対話を小論文に | しゃべった言葉の中に、もう文章の種はある。話したことを書き言葉に置き換えて、自分の考えを紙の上に立たせる。 |
  | 07 | Yes, and 面接ラボ | 面接は試験じゃなく、対話。相手の言葉に「はい、そして」で乗っかる即興の練習場。 |
  | 08 | 二重円と旅の地図 | 「自分がやりたいこと」と「世界が求めていること」の重なりを探して、ここから先のルートを自分の手で描く。 |

### S4｜世界の教室から（sg-world）

- 構成: 事実カード3〜4枚（PC: 2×2グリッド、SP: 縦積み）。各カードは`craft-paper--warm`＋国名の荷札（`craft-label`流儀）。**国旗・国旗絵文字は使わない。**
- カード文言（確定稿。**Sonnetはこれ以外の事実を創作・追加しないこと**）:

  1. **イギリス** — イギリスでは「話すこと（オーラシー）」が、読み書きと同じように学ぶべきスキルとして扱われています。
  2. **フィンランド** — フィンランドの教室では、弱みの矯正ではなく「その子の強み」に注目して記録する実践が広がっています。
  3. **国際バカロレア（IB）** — 世界共通の大学入学資格IBでは、「それはどうやって知ったの？」と知識そのものを問う科目（TOK）が必修になっています。
  4. **アメリカ** — アメリカの大学入試では、テストの点数だけでなく、エッセイ＝「自分の物語」が合否を左右します。

  ※文言は`【要確認】`（§7-4）。実装はこのまま進めてよいが、公開前にオーナーがファクトチェックする。
- 締めの一文（カードの下、中央）:

  > 怪しい独自メソッドではありません。世界の教室で当たり前に行われていることを、日本の入試のかたちに合わせて束ねたコースです。

### S5｜総合型選抜とは（sg-parents 開始）

- **声の切り替え**: セクション冒頭に点線の区切り線＋中央に小さく:

  > —— ここから、保護者の方へ ——

  以降（S5〜S8）の長文段落は`font-family: var(--font-noto)`。トーンは説明調（ただし断定・煽りは禁止のまま）。
- 内容（3ブロック、図解はCSSのみで作る。画像を生成・追加しない）:
  1. **学力の3要素**（紙片3枚を横に並べる）: ①知識・技能 ②思考力・判断力・表現力 ③主体性を持って多様な人々と協働して学ぶ態度 ——総合型選抜は、この②③を書類と対話で見る入試です。
  2. **志望理由書の4つの問い**（付箋4枚）: きっかけ／いま学んでいること／大学で学びたいこと／その先で何をしたいか。S3の8回は、この4つに自分の言葉で答えられるようになるための旅です。
  3. **評定平均について**（注記調の1段落）:

     > 評定平均を出願要件にしている大学もありますが、それは多くの場合「足切り」の基準にすぎません。合否を分けるのは、志望理由の物語に説得力があるかどうか。だからこのコースは、点数ではなく物語を育てます。

### S6｜FAQ（sg-faq）

- 構成: `<details>/<summary>`式（S3と同じ`sg-acc`を流用）。Qの頭にアンバーの「Q」スタンプ。
- **断定的な合格保証・煽りは書かない。事実と設計思想で答える。** 以下3問が確定稿:

  1. **Q. 内申点や出席日数が心配です。**
     A. 評定や出欠を出願要件にしない大学は多数あります。まず面談で、お子さんに開かれているルートを一緒に確認しましょう。
  2. **Q. 人と話すのが苦手なのですが。**
     A. このコースは「話さない権利」の保障から始まります（このページの3つのルールをご覧ください）。手で作ることから言葉が生まれる回もあります。
  3. **Q. 通信制高校でも大丈夫ですか？**
     A. はい。むしろ時間の自由度が、探究活動の強みになります。

- FAQPageのJSON-LDは**実装しない**（noindexページのため無意味。公開時チェックリスト§8で追加判断）。

## §9 合格ライン（機械的判定）と検収方法

実装完了の条件。**すべて満たすこと。**

1. `npm run build` が成功し、実装前と比べて**新規のエラー・警告を増やしていない**（追加コードの型エラー0。既存の警告は対象外）
2. `npm run dev`（ポート3002）で `http://localhost:3002/sogo-senbatsu` にS1〜S8の全8セクションが順に表示される
