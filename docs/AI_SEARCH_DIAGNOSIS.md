# AI検索の現状診断:聞く質問10個と記録表(指示書5・初稿 2026/11/17)

ねらい:AIに質問されたとき、CLAFT／Yononakaが「正しい内容で」出てくるかを、まず実際に確かめる。
優先する相手は2種類:対話の場を探す人、学校以外の学びを探す保護者。

## やり方(1回30〜40分)

1. ChatGPT・Gemini・Perplexity の3つで、下の質問を1つずつ聞く。
2. ログインしていない状態か、新しいチャットで聞く(過去の会話に引っぱられないように)。
3. 質問は書いてあるとおりに入れる。言いかえない。
4. 答えを見て、記録表に書く。
5. 月に1回、同じ質問で同じことをする。変化を見る。

## 記録表(質問1つ × AI 1つで1行)

| 日付 | 質問 | AI | CLAFT/Yononakaは出た？ | 内容は正しい？ | 引用されたページ | 代わりに出た団体・サイト | 気づいたこと |
|---|---|---|---|---|---|---|---|
| | A1 | ChatGPT | 出た／出ない | 正しい／違う(どこが) | | | |

「内容は正しい？」で見るところ:

- 場所(八尾、オンライン)
- 対象の年齢
- 料金(古い金額が出ていないか)
- コースの名前(今はないコース名が出ていないか)
- Yononakaの説明(対話の場であること)

## 結果の読み方と、次の一手

| 結果 | 意味 | 次にすること |
|---|---|---|
| 出て、内容も正しい | そのまま | 引用されたページを覚えておく。そのページを古くしない |
| 出たが、内容が違う | 情報が古いか、サイト間で食い違っている | 食い違っているページを直す。料金・コース名を1か所にそろえる |
| 出ない。ほかの団体が出る | 質問に答えるページがない、または弱い | その質問をそのまま見出しにした記事かFAQをつくる |
| 出ない。どこも出ない | AIが答えを持っていない | 先に答えを置けば拾われやすい。優先して記事にする |

## いまの時点でわかっている弱いところ

診断の前から見えているもの。結果を待たずに直してよい。

- Yononakaのページに、個人向けの料金(Yononakaコース)が載っていない。A1・A3で「個人で参加できるか」が伝わらない。
- スクールHPとラボHPに料金がない。B1・B2で内容が食い違うもとになる。
- ラボHPに、フリースクール・不登校の子の受け入れについての記述がない。B1に答えるページがない。
- 「ロボット教室のあと」(B4)にまっすぐ答える記事がない。フェスタのパネルの内容(扉3「好きは、変わっていい」)が、そのまま記事の材料になる。

## 記事の書き方の型(AIに引用されやすくする)

1. タイトルを、人が聞く質問の形にする。
2. 最初の2〜3文で、質問に答えきる。理由やエピソードはそのあと。
3. 見出しも質問の形にする。
4. 数字や事実は、表にまとめる。
5. だれが書いたか、どこの教室かを毎回書く(八尾・オンライン・対象の年齢)。
6. 教室で実際にあったことを1つ入れる(ほかのサイトにない情報になる)。

既存記事「好きなことばかりで大丈夫？」は、この型にすでに近い。

## 確認が必要なこと

- リポジトリの方針書(docs/SEO_GEO_STRATEGY.md)は「Search Console・GA4は未導入」としている。サイトには計測タグのコードがあるので、実際に動いているかを確認する。
- 方針書の「主な相手は小5〜中3の保護者」に、今回の「対話の場を探す人」を足すかどうか。
- 診断は、この作業環境からは実行できていない。上の質問を、手元のブラウザで聞く必要がある。
