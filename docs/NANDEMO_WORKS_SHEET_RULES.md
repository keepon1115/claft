# なんでも展示会 作品更新ルール（スプレッドシート → Supabase）

なんでも展示会の作品一覧（`/futurecraft/Exhibition2611` など）は、Googleスプレッドシートに書いた内容を AI が取り込みスクリプト経由で Supabase の `works` テーブルに反映して更新する。
**スプレッドシート＝オーナーが編集する場所／DB（works）＝いまページに出ている内容（正）**。ページのコードは変更しない。反映はDB書き込みなので、**デプロイ不要で即ページに出る**。

- シート：<https://docs.google.com/spreadsheets/d/1yAAM9b_eE5aR7NQ4esVQrUkBb828mbEVajkMH6PP_3I/edit>
- ファイルID：`1yAAM9b_eE5aR7NQ4esVQrUkBb828mbEVajkMH6PP_3I`（Google Drive連携で読む）
- 展示会slug：11月＝`nandemo-2026-11`（次回以降は `/admin/exhibitions` で作った slug を指定）
- ラボのストーリーズ（[LAB_STORIES_SHEET_RULES.md](./LAB_STORIES_SHEET_RULES.md)）と同じ運用。違いは反映先がコードではなくDBであること。

## コピペ用プロンプト

```
なんでも展示会の作品を、スプレッドシートの内容で更新をお願いします。
シート：https://docs.google.com/spreadsheets/d/1yAAM9b_eE5aR7NQ4esVQrUkBb828mbEVajkMH6PP_3I/edit
ルール：docs/NANDEMO_WORKS_SHEET_RULES.md を読んでから作業してください。
まずお試し実行（--dry-run）の差分一覧を見せて、OKしたら反映してください。
```

## シートの見方（1タブ・1行目が見出し）

1行 = 1作品。列は**見出し名**で読む（順番を入れ替えてもよい）。

| 列 | 必須 | 中身 |
|---|---|---|
| 作品名 | 必須 | ページに表示される |
| 名前 | 必須 | **ページには出ない**（非公開）。同じ作品かどうかの判定用（DBでは `works.author_nickname`） |
| 動画URL | どちらか | YouTube のURL（`https://youtu.be/…` など）。あれば動画が埋め込まれる |
| 作品リンク | どちらか | `https://` で始まるURL（ゲーム・アプリ等）。あれば「作品はこちら」ボタンになる |
| 削除 | 任意 | 消したい行にだけ `削除` と書く |

- 動画URLと作品リンクは**どちらか一方だけでもOK**。両方空の行はエラー。
- 作品リンクは DB の `works.story_made` 列に保存される（この展示会では未使用の列を流用）。ページ側は `ExhibitionWorks2611Content.tsx`。
- 一覧は提出順（DBへの登録順）に並ぶ。

## AIが守る手順

1. シートを `read_file_content` で読む（Google Drive連携）。
2. スクラッチパッド等の一時ディレクトリに UTF-8 の CSV として書き出す（見出しはシートのまま。プロジェクト内にCSVを残さない）。
3. **お試し実行**：`npm run import:nandemo-works -- <CSVパス> [展示会slug] --dry-run`。DBは変更されず、追加／更新（変更前→変更後）／削除／変化なしの一覧が出る。
   - 入力チェックNG（必須の空欄・URL不正・両方空・重複行など）が出たら、**何も書き込まれない**。行と理由をオーナーに伝えて終わる。
4. 差分一覧をオーナーに見せ、OKをもらう。**削除がある場合は「コメントN件も一緒に消える」ことを明示して確認**する。
5. OKが出たら `--dry-run` を外して本番実行。結果（追加◯・更新◯・削除◯）を報告する。
6. ページ（`/futurecraft/Exhibition2611`）で表示を確認するよう伝える。
7. コミット・プッシュは、指示があった時だけ行う（DB反映だけならコード変更は無い）。

## 注意

- **シートに無い作品には触らない。** 消したい作品は行を消さず `削除` 列で指定する（行を消しても「消したのか書き忘れか」区別できないため）。
- 同じ作品かどうかは **作品名＋名前の完全一致**で判定する。どちらかを書き換えると「別作品」として追加され、古い方は残る（コメントも古い方に付いたまま）。表記を直したいときは、AIに「作品名を直したい」と伝えて手動で更新する。
- 名前の表記ゆれ（全角スペース有無など）で同じ作品名が二重登録されそうなときは、警告が出る。
- 削除すると、その作品のコメント・リアクションも**元に戻せない形で消える**。
- 展示会（`exhibitions`）とリアクション種別は、先に `/admin/exhibitions` で作っておく必要がある。無いとスクリプトが「展示会が見つかりません」で止まる。
- サービスキー（`.env.local` の `SUPABASE_SERVICE_ROLE_KEY`）が必要。Supabase MCP は使わない（未認証のため）。
