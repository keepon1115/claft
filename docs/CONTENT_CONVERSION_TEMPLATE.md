# 記事1本を、カルーセルとリールに変える型(指示書6・初稿 2026/11/17)

止まっていたのは「記事を投稿用に作り直すところ」。ここを、毎回同じ手順でできるようにする。

## 決まりごと

- スクールの声で出す。顔も名前も出さない。
- 素材は、グラレコ画像、作品や手元の映像、AI音声、テロップ。
- あおらない。「今だけ」「差がつく」は使わない。
- 1つの記事から、言いたいことは1つだけ取り出す。

## 手順(記事1本につき、合計60〜90分が目安)

| # | すること | 出てくるもの | 目安 |
|---|---|---|---|
| 1 | 記事から「心の声」と「答え」を1文ずつ抜く | 2文 | 5分 |
| 2 | 例を1つ選ぶ(記事の中から。なければ教室の出来事) | 例1つ | 5分 |
| 3 | 下の「変換シート」を埋める | シート1枚 | 15分 |
| 4 | グラレコを1枚つくる(画像生成) | 画像1枚 | 15分 |
| 5 | カルーセル5枚をCanvaの型に流し込む | 画像5枚 | 15分 |
| 6 | リール20〜30秒をCanvaの型に流し込む | 動画1本 | 15分 |
| 7 | キャプションとLINE用の3行を書く | 文2つ | 10分 |

手順1〜3と7は、記事を貼って「変換シートを埋めて」とAIに頼めば下書きが出る。人がやるのは、例を選ぶことと、言葉を直すこと。

## 変換シート(これを埋めれば、あとは流し込むだけ)

| 項目 | 書くこと |
|---|---|
| 記事 | タイトルとURL |
| 心の声(1文) | 保護者が言いそうな言葉で。「？」か「…」で終わる |
| 答え(1文) | 20字以内。言い切る |
| 例(2〜3文) | 子どもの様子が目に浮かぶもの1つ |
| CLAFTでは(1文) | 教室でしていること1つ |
| 問いかけ(1文) | 読んだ人に返す問い |
| 映像 | リールで使う手元・作品の映像(どの素材か) |

## カルーセル5枚の型

| 枚 | 中身 | 文字量 |
|---|---|---|
| 1 | 心の声(大きく1文) | 20字まで |
| 2 | 答え(大きく1文) | 20字まで |
| 3 | 例(グラレコ1枚) | 絵が主役 |
| 4 | CLAFTでは | 40字まで |
| 5 | 問いかけ＋「くわしくはプロフィールのリンクから」 | 40字まで |

## リール20〜30秒の型

| 秒 | 映像 | テロップ | AI音声 |
|---|---|---|---|
| 0〜4 | 手元のアップ | 心の声 | (読む) |
| 4〜12 | 手元・作品の映像2カット | 例を2行で | (読む) |
| 12〜20 | グラレコをゆっくり寄る | 答え | (読む) |
| 20〜26 | 作品 | 問いかけ | (読む) |
| 26〜30 | ロゴ | CLAFT | (なし) |

## キャプションの型

> 〔心の声〕
>
> 〔答え〕
>
> 〔例を2〜3文〕
>
> 〔CLAFTでは〕
>
> 〔問いかけ〕
>
> くわしくはプロフィールのリンクから。
> #〔基本タグ〕 #〔テーマのタグ〕

## LINE・Weekly Keepon 用の3行

> 〔心の声〕
> 〔答え〕。〔例を1文〕
> 記事はこちら → 〔URL〕

## 実例:記事「好きなことばかりで大丈夫？」

### 変換シート

| 項目 | 内容 |
|---|---|
| 記事 | 「好きなことばかりで大丈夫？」──好きは学びの入口で、目的地じゃない /blog/suki-wa-manabi-no-iriguchi |
| 心の声 | 好きなことばかりで、大丈夫？ |
| 答え | 好きは、学びの入口。 |
| 例 | ゲームが好きな子が、「なんでこんなにやめられへんのやろ？」と調べはじめる。レベルが上がるタイミング、ごほうびが出る間隔。気づけば、人がやる気になる仕組みを学んでいます。 |
| CLAFTでは | 好きなことや気になることから、自分のテーマを立てて探究します。 |
| 問いかけ | 最近、時間を忘れて夢中になっていることは何ですか？ |
| 映像 | ゲームをつくっている手元、キーボード、画面のアップ |

### カルーセル

1. 好きなことばかりで、大丈夫？
2. 好きは、学びの入口。
3. (グラレコ:ゲームが好きな子 → 心理学×ものづくり。配信2枚目の左半分)
4. CLAFTでは、好きなことから自分のテーマを立てて探究します。
5. 最近、時間を忘れて夢中になっていることは何ですか？ くわしくはプロフィールのリンクから。

### リール

| 秒 | 映像 | テロップ・AI音声 |
|---|---|---|
| 0〜4 | ゲームをつくる手元 | 好きなことばかりで、大丈夫？ |
| 4〜12 | 画面のアップ、メモを書く手 | 「なんでこんなにやめられへんのやろ？」調べてみると、人がやる気になる仕組みが見えてきた。 |
| 12〜20 | グラレコに寄る | 好きは、学びの入口。 |
| 20〜26 | できた作品 | 最近、夢中になっていることは何ですか？ |
| 26〜30 | ロゴ | CLAFT |

### キャプション

> 好きなことばかりで、大丈夫？
>
> 好きは、学びの入口です。
>
> ゲームが好きな子が、「なんでこんなにやめられへんのやろ？」と調べはじめる。レベルが上がるタイミング、ごほうびが出る間隔。気づけば、人がやる気になる仕組みを学んでいます。
>
> CLAFTでは、好きなことや気になることから、自分のテーマを立てて探究します。
>
> 最近、時間を忘れて夢中になっていることは何ですか？
>
> くわしくはプロフィールのリンクから。

### LINE用

> 好きなことばかりで、大丈夫？
> 好きは、学びの入口。ゲームが好きな子は、気づけば「人がやる気になる仕組み」を学んでいます。
> 記事はこちら → https://claft.keeponlearning.fun/blog/suki-wa-manabi-no-iriguchi
