■ 記録先：発信ダッシュボード

記録はNotionのデータベース「発信ダッシュボード」に1行追記します。

【初回のみ】「発信ダッシュボード」DBが無ければ、まず作成してください。カラムは以下：
　・週（テキスト）……投稿日が属する週。例：2026-W26 / 6月第4週
　・媒体（選択）……Blog / X / Instagram / note
　・タイトル（テキスト）……元記事タイトル
　・URL（URL）……投稿のURL（無ければ空欄可）
　・投稿日（日付）
　作成したら、その database_id をこのファイルの末尾「DBメモ」に追記提案してください（次回から検索不要にするため）。

【毎回】上記DBに1行追加する。
　・同じ記事を複数媒体に出した場合は、媒体ごとに1行ずつ。
　・記録が終わったら、その週の累積（媒体別の本数）を1〜2行で報告し、「今週はXが○本、Instagramが○本たまっています」と可視化する。

■ やらないこと

・記事の中身の評価・添削はしない（それはルーターAI・文章執筆くんの仕事）。
・数字を創作しない。投げられた事実だけを記録する。
