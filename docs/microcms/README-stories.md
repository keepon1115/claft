# microCMS「stories」セットアップ手順

ラボ上部の「ストーリー」を microCMS で管理するための資料です。
ファイル: `stories-import.csv`（このフォルダ）

---

## 1. スキーマ（フィールド）チェックリスト

API「stories」を、**フィールドIDを下記のとおり**に作成してください（IDが1文字でも違うと表示されません）。

### トップ階層（← これがCSVで一気に入る部分）

| フィールドID | 種類 | 必須 | 補足 |
|---|---|---|---|
| `slug` | テキスト | 任意 | URLに使う英字（event 等）。未入力でも可 |
| `label` | **テキストエリア** | ◯ | 円の下の文字。**改行で2行**になる（テキストエリアにすること） |
| `order` | 数字 | ◯ | 並び順。小さいほど左（1,2,3…） |
| `emoji` | テキスト | 任意 | 写真が無いとき円に出る絵文字 |
| `ringTheme` | セレクト（**複数選択オフ**） | 任意 | 選択肢の値を `default` / `alt` / `navy` の3つに |
| `ringImage` | 画像 | 任意 | 円のサムネ写真（**CSV不可・手動アップ**） |
| `hpUrl` | テキスト | 任意 | 最後のカードの「詳細ページを見る→」先 |

### cards（全画面カード／← CSV不可・手入力）

> ⚠️ **現状ここが「画像」型になっているので要修正。**「画像」を削除し、`cards` を **繰り返しフィールド** で作り直してください（下の「カードの直し方」参照）。

| フィールドID | 種類 | 補足 |
|---|---|---|
| `cards` | **繰り返しフィールド** | 下のカスタムフィールドを複数並べる |

`cards` の中のカスタムフィールド：

| フィールドID | 種類 | 補足 |
|---|---|---|
| `title` | テキスト | カードの見出し |
| `text` | テキストエリア | 本文 |
| `emoji` | テキスト | 大きく出る絵文字 |
| `theme` | セレクト（複数選択オフ） | 値を `navy` / `orange` / `green` に |
| `cardImage` | 画像 | 全画面の背景写真（任意・手動アップ） |

#### カードの直し方（画像 → 繰り返しフィールド）
1. 画面右上の **「カスタムフィールド」** を開き、新規作成。フィールドID例 `card`、上の5項目（title/text/emoji/theme/cardImage）を追加して保存。
2. APIスキーマに戻り、いまの `cards`（画像）を **× 削除**。
3. 「＋フィールドを追加」→ フィールドID `cards`／種類 **繰り返しフィールド** を選び、1で作った `card` カスタムフィールドを指定して保存。

> カードが未登録でも、ストーリー自体は表示されます（絵文字＋ラベルの1枚＋「詳細ページを見る→」が自動表示）。なので **CSVだけ先に取り込んでも動きます**。カードは後からゆっくり追加でOK。

> ⚠️ `ringTheme` と `theme` は**セレクト**にしてください。「複数選択」をオンにしても動きますが、選択肢の**値（value）**は必ず上記の英字にしてください（表示名は日本語でもOK）。

## 2. CSVインポート手順（トップ階層をまとめて投入）

1. microCMS管理画面 → API「stories」→ コンテンツ画面の **「インポートする」**
2. `stories-import.csv` を選択
3. 文字コード **UTF-8**、1行目をヘッダー（フィールドID）として取り込む
4. 6件（event / photo / happyokai / yononaka / career / students）が作成されます

> `label` の改行が反映されない場合は、`label` が「テキスト（単一行）」になっている可能性大。**「テキストエリア」**に直して再インポート、または各コンテンツで手動改行してください。

## 4. 画像サイズの目安（手動アップ）

| 用途 | フィールド | 推奨サイズ・比率 |
|---|---|---|
| 円のサムネ | `ringImage` | 320×320px（正方形 1:1・中心に被写体） |
| 全画面の背景 | `cardImage` | 1080×1920px（縦長 9:16） |

> 画像を入れなければ `emoji` が表示されるので、写真は後から少しずつ追加でOKです。
