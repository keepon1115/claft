## 0. 前提・不可侵事項（実装前に必ず読む）

### 0-1. ブランド・デザイン規約（変更禁止）
- フォント: Zen Maru Gothic / Noto Sans JP。ブランドカラー `#34c6be`（`--brand`）。変更禁止。
- デザイン哲学 "Unfinished & Crafting"（紙・テープ・手書き・スクラップブック）。新規セクションもこの世界観で作る。
- クラフトデザインシステムの規約:
  - 文字サイズに vw の clamp を書かない。`--text-*` トークン（cqi ベース）を使う。
  - 色は `globals.css` の `:root` トークンが単一ソース。生 hex 直書き禁止（`rgb(var(--*-rgb) / alpha)` 参照）。
  - 共通部品を使う: `.craft-paper` / `.craft-tape` / `.craft-sticker` / `.craft-label` / `.craft-highlight` /
    `components/craft/`（HandDrawn・DoodleIcon・SectionTitle）。絵文字アイコンは DoodleIcon を優先。
  - ページ専用 CSS は `globals.css` にページ接頭辞レイヤーで置く（トップ=`hp-*`、claft-hope=`ho-*`、courses=`cs-*`）。
    新規コンポーネントのクラスもこの流儀に従う（例: 診断=`hp-diag-*`、保護者の声=`hp-voice-*`）。
  - ホバーは CSS クラスで（`onMouseEnter` の style 書き換え禁止）。
  - クリーム色 `--cream` の上の白文字はコントラスト不足。アクセントには深いアンバー `224 158 22` を使う。
- オープニングアニメーション `.opening-overlay`（黒背景・白文字・金グロー）は**オーナー要望により演出を変えない**。
  ※本指示書では「2回目以降は出ない現仕様の維持＋スキップ操作の追加」のみ提案（→ §3-6）。

### 0-2. 文言の扱い（重要）
- オーナー方針:「既存の文言・コンテンツの勝手な変更・省略は不可」。
- 本指示書に含まれる新コピーはすべて**ドラフト案**。実装時はドラフトのまま組み込んでよいが、
  **既存文言を削除・書き換える箇所は §5 の「文言承認リスト」に列挙してあり、オーナー確認が完了してから反映**すること。
  未承認の間は「既存文言は残して、位置や折りたたみ状態だけ変える」実装に留める。
- 既存コンテンツは削除ではなく「移動」「アコーディオン格納」「要約＋詳細展開」で扱う。

### 0-3. CVゴール（オーナー決定済み）
- **LINE登録と無料体験フォームの並列2択**。使い分けの提示:
  - 「まず気軽に聞きたい」→ LINE（https://lin.ee/wcsFK9A）
  - 「体験してみたい」→ /contact?type=taiken（体験申込フォーム）
- どちらのボタンにも「押したら何が起きるか」のマイクロコピーを必ず添える（§3-4）。

### 0-4. 技術メモ
- `(site)` 配下の本文に置いた JSON-LD/script は SiteGrid（useSearchParams）経由のため静的 HTML に残らない。
  構造化データを足す場合は root layout の `<head>` に置く。FAQPage JSON-LD はトップの `<FAQ jsonLd />` が単一出力点（重複させない）。
- reveal アニメーションは SiteGrid のグローバル observer 任せ（`.reveal` を付けるだけ）。
- GA4 計測は `lib/analytics.ts` の `trackEvent` を使う。

## 2. 改善戦略（結論）

1. **トップを「保護者の意思決定ページ」に再設計する。**
   構成: ヒーロー刷新 → **簡単診断（3問でコース提案）** → 保護者の声 → CLAFTの学び → 料金早わかり → 入会までの流れ → FAQ拡充 → 子ども以外の導線。
2. **CTAを「LINE｜体験」の並列2択コンポーネントに統一**し、全ページ同じ見た目・同じマイクロコピーで置く。
3. **/claft-hope を「保護者を口説く物語ページ」に再構成**（共感→問題→CLAFTの答え→子どもの変化→代表の想い→CTA）。
4. 社会的証明（保護者の声・実績数字・代表の顔）を新設。実素材はオーナー提供（§4）。素材が届くまでプレースホルダー構造で実装。

実装フェーズ:
- **Phase 1（効果最大・素材不要）**: CTA統一コンポーネント／トップのヒーロー改修／簡単診断／料金早わかり／FAQ拡充／ReserveCTA改修
- **Phase 2**: /claft-hope 再構成
- **Phase 3（素材到着後）**: 保護者の声／代表メッセージ／実績数字の差し替え
