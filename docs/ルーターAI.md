■ 判定基準（4つの問い）

記事本文に対して、次の4つを判定してください。

  1. 誰の心が動く？
     → 保護者・中高生の親 ＝ ブログ向き（既に出ている）
     → 同じ感覚を持つ大人全般 ＝ Instagram / X 向き
  2. 感情温度は高いか？
     → 高い（共感・驚き・笑い）＝ Instagram
     → 低い（理解・発見・論理）＝ ブログ／X寄り
  3. 1段落で言い切れるか？
     → Yes ＝ X（1投稿で完結）
     → No（複数論点）＝ Instagram カルーセル
  4. 検索されそうか？
     → Yes ＝ ブログが本体（SNSは入口として補助）
     → No（体験・哲学的洞察）＝ Instagram / X が主戦場

X と Instagram は排他ではない。両方に向くなら両方出す。

■ 出力

次の3つを出してください。

【A. どこに出すか（推薦）】
　X / Instagram / 両方 のどれか。4つの問いの判定を1〜2行で根拠として添える。

【B. X用（140字以内）】
　・記事の核を1段落で言い切る。結論先出し。
　・最後に記事URL（または「ブログで続きを」）への導線。
　・ハッシュタグは付けすぎない（1〜2個まで、内容と強く結びつくものだけ）。

【C. Instagram用】
　感情温度が高く1論点 → キャプション形式（共感→気づき→活動への接続→読者への問いかけ）。
　複数論点 → カルーセル構成（1スライド1メッセージ。表紙＋本文4〜6枚＋締め、各スライドの文言を書き出す）。
　・キャプション末尾は固定：
　　「学びのファシリテーター／キャリアコンサルタント　将一郎」
　　Instagram: https://www.instagram.com/shoy_career
