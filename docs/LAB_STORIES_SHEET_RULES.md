# ラボ ストーリーズ更新ルール（スプレッドシート → stories.data.ts）

ラボアプリ（/lab）のストーリーズは、Googleスプレッドシートに書いた内容を AI が [lib/lab/stories.data.ts](../lib/lab/stories.data.ts) に反映して更新する。
**スプレッドシート＝オーナーが編集する場所／stories.data.ts＝いまアプリに出ている内容（正）**。アプリのコードは変更しない。

- シート：<https://docs.google.com/spreadsheets/d/1wktkG6QJdNfpMQQ7uQOaohSGTgHI3gpx0qk8SwzuT8Q/edit>
- ファイルID：`1wktkG6QJdNfpMQQ7uQOaohSGTgHI3gpx0qk8SwzuT8Q`（Google Drive連携で読む）

## コピペ用プロンプト

```
ラボのストーリーズを、スプレッドシートの内容で上書きをお願いします。
シート：https://docs.google.com/spreadsheets/d/1wktkG6QJdNfpMQQ7uQOaohSGTgHI3gpx0qk8SwzuT8Q/edit
ルール：docs/LAB_STORIES_SHEET_RULES.md を読んでから作業してください。
まず差分一覧を見せて、OKしたら反映してください。
```

## シートの見方（1タブ・1行目が見出し）

1行 = 「カテゴリ（トップの丸いアイコン）」または「カード（タップで出る全画面の1枚）」。`種別` 列で区別する。
カテゴリ行の直後にそのカードの行を並べると見やすい（並びは「並び順」列で決まるので、行の位置は不問）。
列は**見出し名**で読む（列の順番を入れ替えてもよい）。

| 列 | 種別 | 中身 | stories.data.ts |
|---|---|---|---|
| 種別 | 共通・必須 | `カテゴリ` または `カード` | — |
| カテゴリID | 共通・必須 | 英小文字（event 等）。**一度決めたら変えない** | slug |
| 並び順 | 共通・必須 | カテゴリ行＝トップでの左からの順／カード行＝カテゴリ内の順（1,2,3…） | 配列の順番 |
| カードID | カード・必須 | `event-1` 等。**一度決めたら変えない**。新規は空欄でよい（AIが採番） | cards[].id |
| ラベル | カテゴリ・必須 | 円の下の文字。改行は `/`（`募集/イベント`） | label（`/`→`\n`） |
| 絵文字 | 共通・必須 | カテゴリ＝写真がない時の円の絵文字／カード＝画像がない時の背景絵文字 | emoji |
| リング色 | カテゴリ・必須 | `標準` / `オレンジ寄り` / `紺寄り` | ring: `default` / `alt` / `navy` |
| 円の写真URL | カテゴリ | 円の中のサムネ写真 | ringImageUrl |
| ボタンのリンク | カテゴリ・必須 | 最後のカードのボタン遷移先 | hpUrl |
| ボタンの文言 | カテゴリ | 空なら省略（アプリ側の既定文言） | ctaLabel |
| 更新日 | カテゴリ | YYYY-MM-DD。7日間「New」バッジ | updatedAt |
| 表示期限 | カテゴリ | YYYY-MM-DD。過ぎたら自動で消える | visibleUntil |
| 画像URL | カード | 全画面の背景写真 | imageUrl |
| 動画URL | カード | `/videos/lab-stories/xxx.mp4`（画像より優先） | videoUrl |
| タイトル | カード | 画像だけのカードは空 | title |
| 本文 | カード | 画像だけのカードは空 | text |
| 背景色 | カード・必須 | `紺` / `オレンジ` / `緑` | theme: `navy` / `orange` / `green` |
| カード専用リンク | カード | このカードだけ別ボタンにしたい時 | linkUrl |
| カード専用ボタン文言 | カード | linkUrl がある時のみ有効 | linkLabel |
| 削除 | 共通 | 消したい行にだけ `削除` と書く | 配列から除外 |

`title` と `text` は stories.data.ts で必須なので、空欄のときは `''` を入れる（現状の書式どおり）。

## AIが守る手順

1. シートを `read_file_content` で全部読む（Google Drive連携）。→ stories.data.ts を読む。
2. **IDで突き合わせて**判定する。
   - 両方にあり中身が違う → **上書き**
   - シートにだけある（カードIDが空も含む） → **追加**。カードIDは `カテゴリID-連番`（既存IDと重複しない最小の番号）で採番
   - `削除` 列が `削除` → **削除**（カテゴリを削除したらそのカードも消える）
   - stories.data.ts にだけある → **触らない**（「シートに無い」と報告するだけ。勝手に消さない）
   - 並び順の違い → 並び替え
3. **書き換える前に差分一覧を見せ、OKをもらってから反映する**。表で「上書き◯・追加◯・削除◯・並び替え◯」と、各行の変更前→変更後を出す。差分が0件なら「差分なし」と伝えて終わる。
4. 入力チェック。NGが1つでもあれば反映せず、行と理由を指摘する。
   - URL は `https://` か `/videos/` で始まる
   - 日付は `YYYY-MM-DD`
   - リング色・背景色は選択肢どおり
   - 必須項目が空でない／カード行のカテゴリIDが存在する／カテゴリID・カードIDが重複しない
   - 画像URLと動画URLの両方が空で、絵文字・本文もない「空のカード」でない
5. カードに変更があったカテゴリで「更新日」が空 or 古いままなら、今日（JST）の日付を `updatedAt` に入れる。
6. 空欄＝その項目なし。stories.data.ts からも項目を消す（省略可の項目のみ）。
7. stories.data.ts の型定義・コメント・書式（1カード1行、シングルクォート）は崩さない。反映後 `npx tsc --noEmit` で型を確認する。
8. 反映後に報告する：変更した件数、AIが採番したカードID、AIが入れた更新日。**AIはシートを書き換えられない**ので、採番したIDと更新日はオーナーがシートに書き戻す（書き戻さないと次回また「追加」と判定される）。
9. コミット・プッシュは、指示があった時だけ行う。

## 注意

- 行を消さずに `削除` 列で消す。行を消してもAIは「消したのか書き忘れか」を区別できないため、**シートに無い行は触らない**運用にしている。
- 画像・動画ファイルそのものは扱わない。画像は microCMS 等に上げたURLを貼る。動画は `public/videos/lab-stories/` に置いた上でパスを書く。
- 絵文字セルはシート側で変換されることがあるので、反映時に実際の文字を目視で確認する。
