## 1. 目的とコンセプト

labアプリの「ラボの歩き方」ページ（/lab/roadmap）の雰囲気をそのままに、
紙のチラシへ翻訳する。

**コンセプト: 「指でたどる、学びのすごろくマップ」**

画面の「スクロールして歩く」体験を、紙では「指でたどる」体験に翻訳する。
虹の点線道が4つの面をまたいで続き、「つづきは裏へ→」「2枚目へ→」と
紙をめくる行為自体が"歩く"ことになる。

- 声: **CLAFT＝昼の声**（keepon-brand準拠）。主読者=小学生の保護者、副読者=子ども本人
- ダーク背景・煽りコピー・実績数字の羅列・汎用ピクトグラムは禁止

## 3. 絶対制約

1. **文言は改変禁止**。すべて `RoadmapWalk.tsx` の原文からの「抜粋」のみ。
   要約・言い換え・新規コピーの創作をしない（§6の抜粋叩き台に従う）
2. **フォント**: Zen Maru Gothic（見出し・UI）＋ Noto Sans JP（長文）。他フォント禁止
3. **色**: §4のパレット表の値のみ使用。新色を発明しない
4. 絵文字は使わない。装飾は手描き風の星・マスキングテープ・付箋のみ
5. 完璧すぎる整列を避ける。道の蛇行・吹き出しの1〜2度の傾き・付箋の傾きを意図的に入れる

## 5. 4面の構成

2枚はセット配布前提だが、バラけても成立するよう
**1枚目＝旅の前半＋全体像、2枚目＝旅の後半＋申込情報**の配分。

### 面1（1枚目・表）〈表紙〉

```
┌─────────────────────────┐
│ [KEEP ON LABO]  ←眉ピル          │
│  ラボの                           │
│  歩き方   ←特大900ウェイト2行組   │
│         （「歩き方」はオレンジ）    │
│  ウォーカーのキャラ（大きめ）＋     │
│  ①〜⑦を予告する蛇行ミニマップ     │
│  （虹の点線道・少し傾けて手作り感） │
│  リード文（hero原文そのまま）      │
│  ▶ 指でたどって、歩いてみよう     │
│  [QR: Webで全編を歩ける]          │
└─────────────────────────┘
```

- 見出しは `.roadmap-hero h2` の文法（2行組・2行目 `#ef8a3c` 系オレンジ）を再現
- リード文は原文:「好きを入口に、自分の言葉で伝え、社会や未来のキャリアへ広げていく。スクロールしながら、キープオンラボの学びの旅を一緒に歩いてみてください。」
  - ※「スクロールしながら」の一文が紙と矛盾するが**改変禁止**のため、リード文を1文目までで切って使う（抜粋扱い）
- 画面の進捗バー「01/07」は、ミニマップ上の**スタンプラリー風の空白マス⑦個**に翻訳
- スクロールキュー「スクロールして、歩いてみよう」→ 紙では見出し的要素として
  「指でたどって、歩いてみよう」…は新規コピーになるため**使用不可**。
  代わりに矢印記号＋「①へ」等の記号表現のみで誘導する（文言を作らない）
- QRリンク先: `https://claft-hp.vercel.app/lab/roadmap`【URL要確認・本番ドメイン優先】

### 面2（1枚目・裏）〈前半の旅〉駅①②③

```
┌─────────────────────────┐
│┆← 左端に虹トレイル（赤→橙→黄）  │
│●① [ワクワク] タイトル            │
│┆ 子どもの吹き出し1 ＋ 先生の吹き出し1│
│┆ 帯: note原文（60分・定員5名…）   │
│●② [チャレンジ] …同構成          │
│●③ [ひろげる] …同構成            │
│  保護者のこえ（欄外の付箋1〜2枚）  │
│        「→ つづきは2枚目へ」※記号+既存語彙のみ│
└─────────────────────────┘
```

- 各駅: 番号バッジ（accent地・白文字・手描き風星）＋タグピル（soft地・ink文字）＋タイトル（原文）
- 各駅の背景にその駅の bg 色パネルを敷く（角丸は控えめ、テープ留め風）
- ウォーカーを道の上に小さく配置。**服の色はその駅のテーマ色**（Walker SVGの fill を差し替え）

### 面3（2枚目・表）〈後半の旅〉駅④⑤⑥⑦

- 面2と同じ文法。トレイルは緑→ターコイズ→青→紫
- 4駅入るため対話はさらに短い抜粋。**⑥⑦に面積を厚く**（保護者の関心＝キャリアの話）、④⑤はやや軽く
- 最下部で道がくるんとUターンして裏面へ続く矢印

### 面4（2枚目・裏）〈また、ここから。〉円環＋実務情報

```
┌─────────────────────────┐
│      また、ここから。（原文見出し） │
│   ◯ CLAFTの循環図（円形）        │
│   「つくる、伝える、反応をもらう。 │
│    また好きが育つ。」（echo原文）  │
│  ⑦の紫から①の赤へ道がつながる    │
│─────────────────────│
│ ■ 実務情報ブロック               │
│  1コマ60分・定員5名・いつでも入会OK│
│  場所・料金・体験会【要確認】      │
│  [QR: 受講申し込み]               │
└─────────────────────────┘
```

- 円環図: ⑦の紫の道が①の赤に接続する円。中心に「また、ここから。」
- 締めの本文は loop セクション原文:「ぐるっと一周して、最初の「好き」に戻ってきました。でも今度は、前より一段深く、自分のワクワクが見えているはずです。」
- 問いかけは新規コピー創作禁止のため、原文内の問い（例: 駅⑦先生セリフ等）からの抜粋か、
  **オーナーに文言支給を依頼**（→§9）
- 申込QRリンク先: `https://select-type.com/rsv/?id=3spOTwJvnpQ&c_id=429087`（駅①CTAと同一）
- QRは**全4面でこの2つだけ**（表紙のWeb版＋ここの申込）。駅ごとのQR設置は禁止

## 6. セリフ抜粋の叩き台（オーナー最終確認前提）

原則: 各駅「子ども1つ＋先生1つ」。行番号は STATIONS 配列内の lines のインデックス（0始まり）。

| 駅 | 採用 | 備考 |
|---|---|---|
| ① | child[0] ＋ teacher[1] | note全文も帯で採用 |
| ② | child[0] ＋ teacher[1] | 参加賞状の話（child[2]）は入れば尚可 |
| ③ | child[0] ＋ teacher[1] | |
| ④ | child[0] ＋ teacher[1] | 面3では短め扱い |
| ⑤ | child[0] ＋ teacher[1] | 面3では短め扱い |
| ⑥ | child[0] ＋ teacher[1] | 厚め。child[2]も入れば尚可 |
| ⑦ | teacher[0] ＋ child[1] | ⑦は先生から始まる |

保護者のこえ（付箋風・面2と面3の欄外に1〜2枚ずつ）: 各駅の parent セリフから
**文単位で抜粋**（例: 駅①「家では落ち着きのない子が、あんなに集中して作っている姿、初めて見たかも…！」）。
長すぎる場合も文の途中で切らない。

## 7. ビジュアル翻訳ルール（画面→紙）

| 画面の要素 | 紙での翻訳 |
|---|---|
| スクロール追従ウォーカー | 各駅の道の上に、その駅の色の服のウォーカーを小さく配置 |
| 虹のレールトレイル | 4面を貫く蛇行する点線道。直線にせず、わずかな傾き・揺らぎを入れる |
| 吹き出しアニメーション | 吹き出しをほんの1〜2度ずつ互い違いに傾け、会話のリズムを静止画で出す |
| Sparkles アイコン | 手描き風の星・キラキラ（SVG自作）に置換 |
| 背景色トランジション | 駅ごとの bg 色パネル＋ベースは全面 `#fbf4ec` |
| 進捗バー 01/07 | 表紙のスタンプラリー風マス |
| 「もう一度、はじめから歩く」ボタン | 面4の円環図そのもので表現（ボタンは載せない） |

キャラSVG（Walker / SpeakerSprite 3種）は `RoadmapWalk.tsx` からコピーして流用。
CSS変数（`--roadmap-accent` 等）はインライン値に展開すること。

## 8. 技術実装・入稿仕様

- 置き場所: `print/lab-roadmap-flyer/`（Next.jsアプリの外。デプロイに含めない）
  - `flyer.html`（4面を4ページとして1ファイルに）＋ 必要ならCSS分離
- 仕上がり A4（210×297mm）＋ **塗り足し3mm** → ページサイズ216×303mm で作り、
  トンボは印刷所テンプレに応じて【要確認】。文字・重要要素は仕上がり端から10mm内側
- `@page { size: 216mm 303mm; margin: 0; }` ＋ 面ごとに `page-break-after: always`
- PDF化: headless Chrome（例）
  `chrome --headless --print-to-pdf=flyer.pdf --no-pdf-header-footer flyer.html`
- フォント: Google Fonts をローカルにダウンロードして `@font-face` で同梱
  （オンライン読み込みだとPDF化タイミングで欠けるリスクがあるため）
- QRコード: `qrcode` 系ライブラリ or 生成サービスでSVG生成して埋め込み。
  誤り訂正レベルM以上・仕上がり20mm角以上
- 淡いソフト色は家庭用プリンタで飛ぶため**ネット印刷（CMYK入稿）前提**。
  RGB→CMYK変換で虹アクセントの彩度低下があるため、入稿先の推奨プロファイルを確認
- 用紙推奨: マットコート紙 or 上質紙（ツヤありコートは世界観と喧嘩する）
